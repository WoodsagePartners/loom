# The Loom

A thread engine for Struinova Innovation.

**The job it exists to do:** keep a line of inquiry alive and advancing when the facilitator is not in the room.

Ron is on site one to three days a week for eight to twelve weeks. The work goes cold in between. This is the thing that does not let it.

## Core principles

- The machine asks. It does not answer. The one exception is fact finding, which must mark confidence and name who would really know.
- The machine proposes, the human names.
- Automate the application of a technique, never the judgment.
- Nothing becomes part of the record without a person putting it there.
- Chains terminate, loops drift. Overnight work has a defined end.
- Thinking should be demonstrably deliberate. Chosen friction is a feature.
